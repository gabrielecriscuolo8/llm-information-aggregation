# Saved Results

The readable result folders contain the main CSV tables, event/cell-level observations, decision logs, frozen worlds, HTML reports, and validity audits used in the repository summary.

The complete raw archives in `raw_runs/` additionally contain:

- all prompts and raw model responses;
- atomic experiment checkpoints;
- model and runtime metadata;
- implementation and protocol fingerprints;
- retry and token-accounting records.

These archives are preserved so that the published summaries can be audited against the original completed runs. They are generated outputs, not input data used to train or fine-tune a model.
