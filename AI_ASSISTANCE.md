# AI Assistance Disclosure

This is an independently led project by Gabriele Criscuolo. There are no human collaborators.

## Author's contribution

Gabriele Criscuolo:

- formulated the research question and selected the direction of the project;
- decided which mechanisms and baselines should be compared;
- evaluated the pilot results and identified the need for a stronger V2 baseline;
- made the main protocol and interpretation decisions;
- ran the experiments locally using Qwen through Ollama;
- reviewed the outputs and interpreted the results with AI assistance.

## Use of generative AI

Generative AI was used to:

- translate experimental requirements into Python code;
- draft and refine tests, validation checks, and reporting code;
- assist with debugging and code organization;
- support analysis, documentation, and interpretation.

The code should therefore be described as **AI-assisted**, not as written manually without assistance. Responsibility for the published design, execution, claims, and errors remains with the project author.
